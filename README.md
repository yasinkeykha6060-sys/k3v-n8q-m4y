# نامه برای نیایش

یک صفحهٔ عاشقانه که با HTML و CSS و JavaScript خالص روی GitHub Pages باز می‌شود. هر بار که صفحه تازه شود، از پاکت نامه شروع می‌شود و چیزی ذخیره نمی‌شود.

## عوض کردن متن‌ها

همهٔ جمله‌ها داخل آرایهٔ `CONFIG` در بالای `script.js` هستند. هر آیتم این شکل را دارد:

```js
{ type: "text", text: "متن صفحه", buttonLabel: "ادامه" }
```

`type` یکی از این‌هاست: `envelope`، `text`، `big`، `pineapple`، `voice`، `finale`.

متن را همان‌جا عوض کن. علامت‌های داخل جمله را برندار، چون صفحه همان را نشان می‌دهد.

## عوض کردن صدا

دو فایل داخل پوشهٔ `assets` هستند:

- `assets/kalimba.mp3` موزیک پس‌زمینه
- `assets/voice.mp3` صدای ضبط‌شده

برای جایگزینی، فایل جدید را با همین اسم‌ها کپی کن. اسم‌ها کوچک و بدون فاصله بمانند. مسیرها در کد نسبی هستند تا روی GitHub Pages درست باز شوند.

اگر فایلی بیشتر از حدود ۱۰ مگابایت شد، می‌شود با ffmpeg سبک‌ترش کرد، بدون دست زدن به فایل اصلی:

```text
ffmpeg -i "فایل-اصلی.mp3" -c:a libmp3lame -b:a 128k assets/kalimba.mp3
```

## تست روی گوشی

ریپو را Public کن و GitHub Pages را از شاخهٔ `main` و مسیر `/` روشن کن. بعد لینک Pages را در گوشی باز کن.

برای تست روی همین کامپیوتر، داخل پوشهٔ سایت این را بزن و بعد در مرورگر `http://127.0.0.1:8765` را باز کن:

```text
python -m http.server 8765
```

فایل را مستقیم با `file://` باز نکن، چون بارگذاری صدا آن‌جا درست کار نمی‌کند. موزیک با دکمهٔ «بازش کن» شروع می‌شود. این محدودیت خود مرورگر موبایل است.

## این ریپو عمومی است

ریپو Public است. هر کسی لینک را داشته باشد می‌تواند صفحه، متن نامه و هر دو فایل صوتی را باز کند. لینک را فقط برای نیایش بفرست.
